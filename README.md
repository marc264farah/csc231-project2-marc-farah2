# NEON VEIL — Chapter 1: The Dead District

NEON VEIL is a 2D science-fiction horror platformer set in the quarantined city of Veyra-9 in 2196. Subject 09, a former security operative rebuilt with cybernetic technology, fights through the outbreak to reach an extraction tower. His signature move is Phase Strike, a short forward energy-blade lunge with a cooldown.

## Controls

- A/D or Left/Right Arrow: move
- Space: jump (hold for a higher jump)
- Left mouse button: energy-blade attack
- Left Shift: Phase Strike
- Escape: pause or resume

Defeat seven real enemies to unlock extraction. The tutorial enemy does not count. Energy Cells are optional collectibles shown in the HUD.

## Playing the Windows build

Extract the Windows ZIP in `Builds`, then open `NeonVeilChapter1.exe` inside its extracted folder. Keep `NeonVeilChapter1_Data` beside the executable.

## Tools & Credits

The game's concept, character, level direction, and final choices are Marc Farah's. OpenAI Codex was used to help write and revise Unity scripts, assemble the level in the Editor, and refine the interface. OpenAI image generation was used for original character, enemy, environment, and effect artwork. Unity and its installed packages provide the game engine and input system. No existing game characters were intentionally used.

The current music and sound effects use these CC0 audio sources:

- SRG774, [Dark Sci-Fi Audio Pack](https://opengameart.org/content/dark-sci-fi-audio-pack): `victory_4.mp3` extraction cue.
- Ruskerdax, [Bleak Terminal](https://opengameart.org/content/bleak-terminal): `ruskerdax_-_bleak_terminal_theme.mp3` gameplay music (CC0).

- Kenney, [Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds): thruster, metal impact, laser, and force-field effects.

`Jump_CyberTakeoff.wav` combines short sections of Spring Spring's jump sound and Kenney's thruster effect. The gameplay theme is Ruskerdax's CC0 recording. The earlier synthesized audio remains in the project as unused fallback material.
